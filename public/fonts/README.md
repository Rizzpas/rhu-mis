# Fonts Directory

Place your font files here for web loading:
- `CameraPlainVariable.woff2` (Recommended, web font)
- `CameraPlainVariable.ttf` (TrueType font)

The application is already configured to automatically load "Camera Plain Variable" from:
1. Local system fonts (`Camera Plain Variable`, `ABCCameraPlainVariable`, `CameraPlainVariable`)
2. `/fonts/CameraPlainVariable.woff2`
3. `/fonts/CameraPlainVariable.ttf`
